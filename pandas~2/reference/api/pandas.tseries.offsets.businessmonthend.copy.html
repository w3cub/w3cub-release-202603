pandas.tseries.offsets.BusinessMonthEnd.copy

BusinessMonthEnd.copy()

Return a copy of the frequency.

Examples

>>> freq = pd.DateOffset(1)
>>> freq_copy = freq.copy()
>>> freq is freq_copy
False
