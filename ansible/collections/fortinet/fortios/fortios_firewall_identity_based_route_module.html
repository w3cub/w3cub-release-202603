fortinet.fortios.fortios_firewall_identity_based_route module – Configure identity based routing in Fortinet’s FortiOS and FortiGate.

Note

This module is part of the fortinet.fortios collection (version 2.4.0).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install fortinet.fortios. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: fortinet.fortios.fortios_firewall_identity_based_route.

New in fortinet.fortios 2.0.0

Synopsis

  • This module is able to configure a FortiGate or FortiOS (FOS) device by allowing the user to set and modify firewall feature and identity_based_route category. Examples include all parameters and values need to be adjusted to datasources before usage. Tested with FOS v6.0.0

Requirements

The below requirements are needed on the host that executes this module.

  • ansible>=2.15

Notes

Note

Examples

- name: Configure identity based routing.
  fortinet.fortios.fortios_firewall_identity_based_route:
      vdom: "{{ vdom }}"
      state: "present"
      access_token: "<your_own_value>"
      firewall_identity_based_route:
          comments: "<your_own_value>"
          name: "default_name_4"
          rule:
              -
                  device: "<your_own_value> (source system.interface.name)"
                  gateway: "<your_own_value>"
                  groups:
                      -
                          name: "default_name_9 (source user.group.name)"
                  id: "10"
