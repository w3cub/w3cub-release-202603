fortinet.fortios.fortios_web_proxy_isolator_server module – Configure forward-server addresses in Fortinet’s FortiOS and FortiGate.

Note

This module is part of the fortinet.fortios collection (version 2.4.0).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install fortinet.fortios. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: fortinet.fortios.fortios_web_proxy_isolator_server.

New in fortinet.fortios 2.0.0

Synopsis

  • This module is able to configure a FortiGate or FortiOS (FOS) device by allowing the user to set and modify web_proxy feature and isolator_server category. Examples include all parameters and values need to be adjusted to datasources before usage. Tested with FOS v6.0.0

Requirements

The below requirements are needed on the host that executes this module.

  • ansible>=2.15

Examples

- name: Configure forward-server addresses.
  fortinet.fortios.fortios_web_proxy_isolator_server:
      vdom: "{{ vdom }}"
      state: "present"
      access_token: "<your_own_value>"
      web_proxy_isolator_server:
          addr_type: "ip"
          comment: "Comment."
          fqdn: "<your_own_value>"
          interface: "<your_own_value> (source system.interface.name)"
          interface_select_method: "sdwan"
          ip: "<your_own_value>"
          ipv6: "<your_own_value>"
          name: "default_name_10"
          port: "3128"
          vrf_select: "-1"
