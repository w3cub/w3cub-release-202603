cisco.meraki.networks_sm_devices_reboot module – Resource module for networks _sm _devices _reboot

Note

This module is part of the cisco.meraki collection (version 2.21.4).

You might already have this collection installed if you are using the ansible package. It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install cisco.meraki. You need further requirements to be able to use this module, see Requirements for details.

To use it in a playbook, specify: cisco.meraki.networks_sm_devices_reboot.

New in cisco.meraki 1.0.0

Synopsis

  • Manage operation create of the resource networks _sm _devices _reboot.
  • Reboot a set of endpoints.

Note

This module has a corresponding action plugin.

Requirements

The below requirements are needed on the host that executes this module.

  • meraki >= 2.4.9
  • python >= 3.5

Notes

Note

  • SDK Method used are sm.Sm.reboot_network_sm_devices,
  • Paths used are post /networks/{networkId}/sm/devices/reboot,
  • Does not support check_mode
  • The plugin runs on the control node and does not use any ansible connection plugins, but instead the embedded connection manager
  • from Cisco Dashboard API Python(SDK)
  • The parameters starting with dnac_ are used by the Cisco DNAC Python SDK to establish the connection
