QT_WASM_MAXIMUM_MEMORY

Internal WebAssembly maximum memory.

This property was introduced in Qt 6.7.

Note: This property is in technology preview and may change in future releases.

Note: This property is used only if targeting the WebAssembly platform.

Specifies the maximum amount of memory the application can use. Translates into the Emscripten compiler setting of MAXIMUM_MEMORY. The default value is 4GB, which is the maximum for 32-bit WebAssembly.

For more information, see the Emscripten compiler settings.
