class Crystal::Macros::AnnotationDef

  • Crystal::Macros::AnnotationDef
  • Crystal::Macros::ASTNode

Overview

An annotation definition.

Every annotation definition node is equivalent to:

{% begin %}
  {{ node.kind }} {{ node.name }}
    {{ node.body }}
  end
{% end %}
