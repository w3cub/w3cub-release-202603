Description

Products, lifted to functors.

Since: base-4.9.0.0

data Product (f :: k -> Type) (g :: k -> Type) (a :: k) Source

Lifted product of functors.

Examples
Expand
>>> fmap (+1) (Pair [1, 2, 3] (Just 0))
Pair [2,3,4] (Just 1)

>>> Pair "Hello, " (Left 'x') <> Pair "World" (Right 'y')
Pair "Hello, World" (Right 'y')
