Interface CaseTree

All Superinterfaces:
Tree
public interface CaseTree extends Tree
A tree node for a case in a switch statement or expression. For example: 
  case expression :
      statements

  default :
      statements
See Java Language Specification:
14.11 The switch Statement
Since:
1.6
