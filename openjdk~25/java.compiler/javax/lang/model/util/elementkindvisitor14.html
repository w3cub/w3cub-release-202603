@SupportedSourceVersion(RELEASE_25) public class ElementKindVisitor14<R,P> extends ElementKindVisitor9<R,P>
A visitor of program elements based on their kind with default behavior appropriate for the RELEASE_14 source version. For elements Xyz that may have more than one kind, the visitXyz methods in this class delegate to the visitXyzAsKind method corresponding to the first argument's kind. The visitXyzAsKind methods call defaultAction, passing their arguments to defaultAction's corresponding parameters.
