Module jdk.jdeps

module jdk.jdeps
Defines tools for analysing dependencies in Java libraries and programs, including the jdeps, javap, jdeprscan, and jnativescan tools.

This module provides the equivalent of command-line access to the javap, jdeps, and jnativescan tools via the ToolProvider service provider interface (SPI)

Instances of the tools can be obtained by calling ToolProvider.findFirst or the service loader with the name "javap" or "jdeps" as appropriate.

jdeprscan only exists as a command line tool, and does not provide any direct API.

Services

Type Description
ToolProvider
Use ToolProvider.findFirst("javap"), ToolProvider.findFirst("jdeps"), or ToolProvider.findFirst("jnativescan") to obtain an instance of a ToolProvider that provides the equivalent of command-line access to the javap, jdeps, jnativescan tool.
