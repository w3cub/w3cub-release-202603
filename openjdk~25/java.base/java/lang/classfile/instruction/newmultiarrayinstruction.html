Interface NewMultiArrayInstruction

All Superinterfaces:
ClassFileElement, CodeElement, Instruction
public sealed interface NewMultiArrayInstruction extends Instruction
Models a multianewarray instruction in the code array of a Code attribute. Delivered as a CodeElement when traversing the elements of a CodeModel.

A new multi-dimensional array instruction is composite: 

NewMultiArrayInstruction(
    ClassEntry arrayType,
    int dimensions
)
where the arrayType is an array class.
See Java Virtual Machine Specification:
6.5.multianewarray multianewarray
Since:
24
