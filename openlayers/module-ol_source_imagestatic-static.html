Fires:
  • change (BaseEvent) - Generic change event. Triggered when the revision counter is increased.
  • error (BaseEvent) - Generic error event. Triggered when an error occurs.
  • imageloadend (ImageSourceEvent) - Triggered when an image finishes loading.
  • imageloaderror (ImageSourceEvent) - Triggered if image loading results in an error.
  • imageloadstart (ImageSourceEvent) - Triggered when an image starts loading.
