Module: tf.compat.v1.tpu.experimental.embedding

Classes

class FTRL: Optimization parameters for FTRL with TPU embeddings.

class FeatureConfig: Configuration data for one embedding feature.

class QuantizationConfig: Settings for simulated quantization of the tpu embedding table.

class SGD: Optimization parameters for stochastic gradient descent for TPU embeddings.

class TPUEmbedding: The TPUEmbedding mid level API.

class TPUEmbeddingV2: The TPUEmbedding mid level API running on TPU with sparse core accelerator.

class TableConfig: Configuration data for one embedding table.
